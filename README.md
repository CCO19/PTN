# Pas le Temps d'Niaiser (PTN)

PTN est une interface graphique minimaliste développée en .NET 10.0.

Elle permet de télécharger des séries TV (ou des saisons spécifiques) partagées via Freebox OS dont l'arborescence et le nommage respectent la logique suivante :

    <Série>\<Saison #>\<S#E# - épisode.extension>

L'application est fonctionnelle mais toujours en version de test et peut donc présenter des bugs.
